# Containers

AWS is the #1 place for you to run containers and 80% of all containers in the cloud run on AWS. Customers such as Samsung, Expedia, KPMG, GoDaddy, and Snap choose to run their containers on AWS because of our security, reliability, and scalability.

AWS offers multiple container services to help you deploy, manage, and scale containers. Use the chart below to map out which AWS services can be used to run your container workload or visit the services page to learn more about your options and which best suits your needs.

AWS service

Recommended use

Amazon ECR

Use ECR with any AWS container orchestration service to store your container images

Amazon ECS

Use ECS to break monolith apps into microservices, migrate to the cloud, or run batch processing workloads

Amazon EKS

Use Fargate with ECS to launch serverless containers or build a PaaS

Amazon EC2

Use EC2 with any of our management services for the maximum control over your launch type
