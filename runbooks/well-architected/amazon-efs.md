# Amazon EFS

[Amazon Elastic File System (Amazon EFS)](https://aws.amazon.com/efs/)  provides a simple, scalable, fully managed elastic NFS file system for use with AWS Cloud services and on-premises resources. It is built to scale on demand to petabytes without disrupting applications, growing and shrinking automatically as you add and remove files, eliminating the need to provision and manage capacity to accommodate growth.

[

#### Tip #1: Consider using Amazon EFS Infrequent Access

](#tip-1:-consider-using-amazon-efs-infrequent-access)

You can choose from four Amazon Elastic File System (Amazon EFS) Lifecycle Management policies to automatically move files into the EFS Infrequent Access (EFS IA) storage class and save up to 85% as your access patterns change. Additionally, you can now enable Lifecycle Management for all EFS file systems.

EFS IA provides price/performance that’s cost-optimized for files not accessed every day, enabling you to save up to 85% on file storage costs compared to the Amazon EFS Standard storage class. To get started with EFS IA, you enable Lifecycle Management for your file system, which automatically moves files to the lower-cost storage class based on the last time they were accessed. You can now choose age-off policies of 14, 30, 60, or 90 days. Previously, EFS Lifecycle Management used a pre-defined policy to move files into EFS IA.

*   [Optimize Storage Cost with Reduced Pricing for Amazon EFS Infrequent Access](https://aws.amazon.com/blogs/aws/optimize-storage-cost-with-reduced-pricing-for-amazon-efs-infrequent-access/) 

[

#### Tip #2: Consider using Amazon EFS Archive

](#tip-2:-consider-using-amazon-efs-archive)

Amazon EFS Archive is a storage class that is cost-optimized for long-lived file data that is accessed a few times a year or less. With EFS Archive, you have a cost-effective way to retain even your coldest data so that it’s always available to power new business insights. EFS Archive supports the same intelligent tiering experience as existing EFS storage classes, which means that you can now combine the sub-millisecond SSD latencies of Amazon EFS Standard for your active frequently-accessed data with the lower costs of EFS IA and EFS Archive for your colder data. When needed, all your data is accessible from a single EFS file system that’s automatically cost-optimized for a mix of active and inactive data. With EFS Archive, customers can save up to 50% – compared to the reduced price of EFS IA – when storing long-lived, rarely-accessed data.

*   [Optimize your storage costs for rarely-accessed files with Amazon EFS Archive](https://aws.amazon.com/blogs/aws/optimize-your-storage-costs-for-rarely-accessed-files-with-amazon-efs-archive/)
