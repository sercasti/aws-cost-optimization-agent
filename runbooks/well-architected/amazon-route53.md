# Amazon Route53

[Amazon Route 53](https://aws.amazon.com/route53/)  is a highly available and scalable cloud Domain Name System (DNS) web service. It is designed to give developers and businesses an extremely reliable and cost effective way to route end users to Internet applications by translating names like [www.example.com](http://www.example.com)  into the numeric IP addresses like 192.0.
