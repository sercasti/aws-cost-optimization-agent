# AWS Compute Optimizer

[AWS Compute Optimizer](https://aws.amazon.com/compute-optimizer/)  recommends optimal AWS Compute resources for your workloads to reduce costs and improve performance by using machine learning to analyze historical utilization metrics. Over-provisioning compute can lead to unnecessary infrastructure cost and under-provisioning compute can lead to poor application performance.

AWS Compute Optimizer helps you identify the optimal AWS resource configurations, such as Amazon Elastic Compute Cloud (EC2) instance types, Amazon Elastic Block Store (EBS) volume configurations, task sizes of Amazon Elastic Container Service (ECS) services on AWS Fargate, and AWS Lambda function memory sizes

![Compute optimizer](https://static.us-east-1.prod.workshops.aws/public/8844589c-f6be-4752-bd27-0dad323d1eb9/static/images/003_tools/004_compute_optim/compute_optimizer.png)

#### Tip #1: Getting Started

](#tip-1:-getting-started)

First you need to [opt-in](https://aws.amazon.com/compute-optimizer/getting-started/)  for the Compute Optimizer Service. There is [no additional charge](https://aws.amazon.com/compute-optimizer/pricing/) . Go to the AWS Compute Optimizer [console](https://console.aws.amazon.com/compute-optimizer)  and click “opt in”.

Second, if you want detailed recommendation regarding memory, you must [install the Amazon CloudWatch Agent](https://docs.aws.amazon.com/compute-optimizer/latest/ug/metrics.html) .

Then [review](https://console.aws.amazon.com/compute-optimizer)  recommended actions and potential savings provided by checks

![Compute Optimizer](https://static.us-east-1.prod.workshops.aws/public/8844589c-f6be-4752-bd27-0dad323d1eb9/static/images/003_tools/004_compute_optim/recommendations.png?classes=shadow)

You'll get more details in the blog post [AWS Compute Optimizer – Your Customized Resource Optimization Service](https://aws.amazon.com/blogs/aws/aws-compute-optimizer-your-customized-resource-optimization-service/) .
